How to Play

【电脑专属，需键盘鼠标，手机无法操作】Desktop players run through the temple ruins with the keyboard, per the posted note about running as far as possible. This backup game was verified on desktop only, so it remains on computers and is held back from phones.

Tips

  • Tap the green play triangle in the middle of a temple entrance once it has loaded.
  • Read the temple carvings and jungle leaves first, because the scene sets the ruins theme.
  • Keep the first runs calm, learning the running feel before chasing distance.
